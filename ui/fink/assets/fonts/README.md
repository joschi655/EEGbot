# Fonts — Gilmer (nicht im Repo)

Gilmer ist eine kommerzielle Schrift und darf nicht redistribuiert werden —
die `.otf`-Dateien sind deshalb gitignored und bleiben nur lokal.

Fallback-Stack (in styles.css bereits so definiert bzw. so verwenden):
`"Gilmer", "Inter", "Helvetica Neue", Arial, sans-serif` — ohne lokale
Gilmer-Dateien rendert die App mit dem Fallback, Layout bleibt funktional.
