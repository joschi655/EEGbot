A KPI metric with big tabular value, label, and optional trend delta.

```jsx
<Stat label="Konformitätsquote" value="94" unit="%" delta="+2,1 %" trend="up" foot="vs. letzter Monat" />
<Stat label="Offene Fristen" value="7" delta="3 diese Woche" trend="down" />
```

Props: `label`, `value`, `unit`, `delta`, `trend` (`up`/`down`/`flat`), `foot`.
