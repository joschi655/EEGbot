A checkbox with optional label and description. Klein-blue fill when checked.

```jsx
<Checkbox label="Nur überfällige Anlagen" />
<Checkbox label="Automatische Meldung" description="fink reicht 7 Tage vor Frist selbst ein." defaultChecked />
```

Props: `label`, `description`, `disabled`, plus native checkbox attributes (`checked`, `onChange`…).
